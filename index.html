Cold-Chain Spoilage Risk Model

Regression
Python · Pandas · Scikit-learn · Seaborn
  • Predicts a 0–100 spoilage-risk score for 492 refrigerated shipments from 13 operational inputs, including storage temperature, excursion hours, humidity, transit time and door-open events.
  • Compared row deletion, mean imputation and KNN imputation (k=5) for missing data. Deleting rows would have discarded 21% of the dataset.
  • Engineered three domain features (thermal-abuse index, cooling-protection ratio, load-stress index), scaled the inputs and used PCA to inspect structure.
  • Benchmarked four regressors on an 80/20 split. An unconstrained decision tree overfit badly, which is why the comparison matters.
Result: Linear Regression led with R² 0.85 and a mean absolute error of 3.49 points on the 0–100 scale.

Aftershock: Earthquake Data Pipeline

Data engineering
Python · REST API · JSON · CSV
  • Queries the USGS Earthquake REST API for a fixed date window and saves the raw GeoJSON response, so every run can be reproduced.
  • Keeps earthquake-type events only and flattens each into a clean schema.
  • Reports minimum, maximum and average magnitude plus the five strongest events, and exports results to JSON and CSV.
  • Handles failures cleanly: request timeouts, missing fields and empty results all exit with a clear message instead of a crash.
Missing magnitudes are sorted with record["magnitude"] or float("-inf"), so a null value ranks last instead of breaking the comparison.
